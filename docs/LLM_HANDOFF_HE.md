מה נוסף:
- מתאם לשני פורמטי ההמלצות הקיימים, בעברית ובאנגלית ולמאמן/אנליסט/אוהד.
- לקוח Azure OpenAI דרך Responses API עם פלט מובנה, זמן המתנה מוגבל ומטמון.
- ה־LLM בוחר ומסדר ראיות קיימות; הקוד מציג את העובדות והמספרים. הוא אינו
  מחליט על חילוף, משנה שחקנים או ממציא טיעון טקטי חדש.
- גילוי חובה כשהרענון שולט, הצגת פשרות וסימון ברור של גיבוי ללא LLM.
- API נפרד POST /api/explain, כלי CLI ודף בדיקה עם נקודות מהזרם הסינתטי.

להפעלה:
```bash
pip install -e ".[dev,narrative]"
python scripts/serve_narrative.py --port 8772
```
פתיחה: http://127.0.0.1:8772/ . ללא Azure מופיע במפורש deterministic fallback.

ולהציג את התוצאה בשדה נפרד בלי לשנות את rec. בשרת אסינכרוני יש להפעיל את
הקריאה בעובד נפרד ולא לחסום את קליטת האירועים. במעבר דקה/קבוצה יש להתעלם
מתשובת הסבר ישנה. דוגמאות Python ו־HTTP נמצאות ב־LLM_INTEGRATION.md.

coach_intent הוא שדה תצוגה אופציונלי בלבד: attack/balanced/defend/unspecified.
הוא אינו מממש את בקרות המאמן ואינו משנה משקולות. כשהחבר יוסיף מטרות ומערכים
למנוע, נוסיף אותם כעובדות מובנות למתאם ולבדיקות, ולא נבקש מה־LLM להסיק אותם.
