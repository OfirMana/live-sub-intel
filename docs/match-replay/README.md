# חדר המשחק — שחזור מחזור 21

UI פשוט בעברית, עם טוטנהאם–לסטר כברירת מחדל. אפשר לבחור גם צ׳לסי–ווסט ברום
וליברפול–ארסנל, ולבחון את נקודת המבט של כל אחת מארבע הקבוצות שבמאגר.

## פתיחה

הורידו `match-replay.zip` (local generated export; not bundled), חלצו ופתחו `index.html` בדפדפן.
הכול כלול בקובץ, ללא התקנות או רשת. GitHub מציג את [קובץ האתר](index.html) כקוד;
כדי לראות את הממשק יש להוריד ולפתוח אותו, או לשרת את תיקיית docs מקומית.

## שימוש

1. בחרו משחק וקבוצה.
2. לחצו **התקדם 5 דקות**. השעון רץ והאירועים מופיעים כשהוא מגיע לזמן שבו התרחשו.
3. בחרו קצב רגיל, מהיר או מיידי. ההרצה נעצרת בכל נקודת בדיקה.
4. לחצו **בדוק חילופים** כשאתם רוצים לחשוף את ההחלטה. היא אינה נפתחת אוטומטית.
5. בחרו כל מועמד מהרשימה כדי להשוות את פרופילי השחקנים, ההפרשים והניקוד.
6. כשאין המלצה, עדיין רואים את כל האפשרויות החוקיות ואת המרחק של כל אחת מהסף.
7. אפשר לחזור חמש דקות, להתחיל מחדש או להמשיך לתוספת הזמן ולשריקת הסיום.

האירועים כוללים בעיטות, שערים, כרטיסים, חילופי מאמן ומחציות. אפשר להסתיר בעיטות.
התוצאה אינה נחשפת מראש. תוספת הזמן של המחצית הראשונה נשמרת לפני המשך המחצית
השנייה; אחרי דקה 90 יש מקטע סיום נוסף, כך שלא נעלמים אירועים מאוחרים.

## משמעות ההדמיה

זהו **שחזור היסטורי אינטראקטיבי**, ולא תחזית לתוצאה אילו בוצע חילוף אחר.
רק חילופי המאמן ההיסטוריים משנים את ההרכב בשחזור. כפתור הבדיקה מציג המלצות;
הוא אינו מבצע אותן. החישובים והסף הקיימים לא שונו במסגרת הוספת הממשק.

ההשוואה מציגה Recent בתוספת תיקון חי ליוצא, מול Recent של המחליף הטרי.
העייפות נספרת בנפרד בניקוד. ניתן לפתוח גם General/Recent שלפני המשחק.
תפקיד המשחק מוצג בנפרד מהתפקיד הראשי בכרטיס, כדי ששחקן רב־עמדתי לא ייראה
כאילו מבוצע עבורו שינוי מערך שאינו נתמך.

כל הכרטיסים קפואים לפני 13.01.2016. עייפות ומעקב פיזי הם אומדנים, והחלופות
לסון ולבראד סמית׳ סינתטיות. התועלת היא ציון מודל, לא הסתברות או שערים צפויים.

## שחזור ובדיקות

```bash
PYTHONPATH=src python scripts/export_match_replay.py
node --test tests/test_match_replay_ui.cjs
python -m http.server 8771 --bind 127.0.0.1 --directory docs
```

פתיחה: `http://127.0.0.1:8771/match-replay/`.
המקורות נמצאים ב־web/match-replay. קבצי StatsBomb הגולמיים נדרשים לבנייה מחדש,
אך אינם נדרשים להפעלת הממשק המיוצא. הבדיקות בוחנות חשיפה בזמן, התאמה לתוצאות
המנוע, מחציות ותוספת זמן, פרופילים והפרש מהסף.
