# Data sources and publication status

The match actions and scripted manager changes are generated by this project. Player/squad priors are historical, primarily 2015/16 metadata, FIFA16-edition attributes and pre-13-January-2016 StatsBomb evidence. The precise FIFA snapshot update date is unverified. SkillCorner A-League 2024/25 position-group aggregates are physical-generation references, not tracking measurements of the displayed players.
