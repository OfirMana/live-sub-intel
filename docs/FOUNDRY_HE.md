# חיבור שכבת ההסבר ל־Microsoft Foundry

המנוע מחליט, וה־LLM רק מסביר. הקוד נמצא ב־`src/subintel/narrative.py`. בלי חיבור ל־Foundry הוא משתמש בתבנית קבועה, כך שהדמו עובד גם בלי רשת.

## 1. יצירת פרויקט

1. ב־ai.azure.com, כשהמתג **New Foundry** דלוק, לוחצים **Create project**.
2. שם הפרויקט: `live-sub-intel`.
3. ב־**Advanced options**:
   - **Subscription**: המנוי שיש בו קרדיט, למשל של ההאקתון או חשבון ניסיון.
   - **Resource group**: יוצרים חדש, למשל `rg-live-sub-intel`. כך קל למחוק הכול בסוף.
   - **Region**: אזור שבו זמין המודל שתבחרו. אם המודל לא מופיע אחר כך, יוצרים פרויקט באזור אחר.
4. **Create**, וממתינים לדף הסקירה של הפרויקט.

אם יש סימן ⚠ ליד **All resources**, מעבירים עליו את העכבר. בדרך כלל זה אומר שאין מנוי פעיל או שאין הרשאה ליצור משאבים.

## 2. פריסת מודל

1. **Discover** בתפריט העליון, ואז **Models**.
2. בוחרים מודל צ'אט קטן ומהיר, למשל `gpt-4.1-mini` או מודל mini חדש יותר. ההסברים קצרים, ומודל גדול לא נחוץ.
3. **Deploy** עם הגדרות ברירת המחדל.
4. רושמים את **שם הפריסה** (deployment name). זה הערך של `FOUNDRY_DEPLOYMENT`.
5. רשות: ב־Playground בודקים שהמודל כותב עברית טובה.

## 3. כתובת ומפתח

בדף הבית של הפרויקט מופיעים **Project endpoint** ו־**API key**.

| משתנה | ערך | סודי? |
|---|---|---|
| `FOUNDRY_ENDPOINT` | ה־Project endpoint (או כתובת המשאב `https://<name>.openai.azure.com`) | לא |
| `FOUNDRY_DEPLOYMENT` | שם הפריסה מסעיף 2 | לא |
| `FOUNDRY_API_KEY` | ה־API key | **כן** |

את המפתח לא מדביקים בצ'אט ולא מכניסים לקוד או ל־git.
- **אצלכם במחשב:** מגדירים אותו כמשתנה סביבה.
- **ב־Claude Code בענן:** הגדרות הסביבה (Edit) ← Network secrets או משתנה סביבה. רק session חדש קולט אותו.

אם המפתח דלף, יוצרים חדש ב־Foundry.

## 4. בדיקה

```bash
pip install -e ".[llm]"
python scripts/explain_recommendation.py --minute 75 --lang he
```

בכותרת של כל הסבר כתוב מאיפה הוא הגיע:
- `llm`: ה־LLM כתב אותו.
- `template`: הוא הגיע מהתבנית. ליד זה מופיעה הסיבה: חסר חיבור, שגיאה, או שה־LLM המציא מספר.

## איך זה עובד

- ה־LLM מקבל רק את ה־JSON מ־`narrative.facts()`: מי יוצא, מי נכנס, צרכים, רווחים, המחיר, עייפות משוערת ורמת הראיות.
- כל מספר בטקסט של ה־LLM חייב להופיע ב־JSON. אם לא, הטקסט נדחה ומוצגת התבנית.
- שלושה קהלים (`fan`, `analyst`, `broadcaster`) ושתי שפות (`he`, `en`).
- החיבור עובר דרך ה־API התואם OpenAI של Foundry (`/openai/v1`). זה הנתיב ש־Microsoft ממליצה עליו במקום ה־SDK הישן, שיוצא משימוש.
